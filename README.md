# 문화관람 PM 보고

비전AI 기반 지능형 문화관람 서비스 시범 구축 사업의 보고 자료를 GitHub Pages로 게시한다.

- 주소: https://deepvisions-git.github.io/pm-reports/
- 이 저장소는 공개(public)다. 누구나 볼 수 있으므로 개인정보·계정·접속정보는 넣지 않는다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 보고 목록(종류별) |
| `<종류>/<YYYY-MM-DD>/index.html` | 보고 한 건. 다른 파일에 의존하지 않는 HTML 한 장 |

보고 종류: `progress`(구현 현황)

## 보고 추가

1. `<종류>/<YYYY-MM-DD>/index.html`을 만든다. 새 종류면 폴더를 새로 만든다.
2. `index.html`의 해당 종류 묶음에 항목을 맨 위에 추가한다. 새 종류면 묶음(`section`)을 추가하고 이 README의 보고 종류에도 적는다.
3. 커밋하고 `main`에 푸시하면 1~2분 뒤 반영된다.
