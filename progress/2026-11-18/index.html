  • 관리자 현황 화면 5개와 재색인 탭은 API가 준비되어 있어 화면 연결만 하면 됩니다.

  • 관람객 서비스는 실기기 점검과 품질 보완을 이어 가며, 남은 기간에 통합 점검을 준비합니다.

산정 기준: 설계 화면 23개와 서비스 백엔드 API를 develop 브랜치 코드와 대조하고, 작업 항목마다 작업량·난이도 가중치를 두어 계산했습니다. 화면 골격만 있고 API 연결 전인 항목은 일부 진행으로 반영했습니다.
